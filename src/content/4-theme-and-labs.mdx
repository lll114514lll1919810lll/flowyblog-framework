站点有两套外观机制：明暗主题和实验室开关。两者都不改组件代码，全部通过 CSS 变量驱动。

## 明暗主题

主题由 `<html data-theme>` 属性驱动。首次绘制前有一段内联脚本先把属性写好，所以刷新页面不会出现「先浅色闪一下再变深色」的情况。跟随系统与手动切换并存，手动选择记在本地。

代码高亮也参与主题：Shiki 同时输出两套颜色到 CSS 变量，切换时纯 CSS 生效。

## 实验室开关

`/lab` 页面提供一组外观实验：书本模式、赛博朋克、液态玻璃渲染器等。开关状态写在 `<html data-labs>` 上，样式以 CSS 变量和选择器的形式集中在 `globals.css`。

## 新增一个实验

两步：

1. 在 `src/lib/labs.ts` 注册开关（id、名称、说明）
2. 在 `globals.css` 加对应令牌覆盖，选择器用 `html[data-labs~="你的id"]`

不需要碰任何组件。个别实验有已知兼容限制，比如书本模式与液态玻璃同时开启时液态玻璃不生效、赛博朋克锁定夜间模式，说明写在 `/lab` 页面上。

## 为什么用 CSS 变量而不是改组件

主题类需求几乎都是「同一套结构、不同一套皮肤」。CSS 变量让皮肤集中在一处，组件保持结构职责，两者互不牵连——新增实验时不会把组件代码越改越乱。
