这篇文章把正文里最常用的元素集中演示一遍，写文章时拿它当对照卡。所有写法都能在源码里直接抄。

## 标题与目录

文章页只收录 `##` 和 `###` 两级标题进目录，`####` 及更深的不收——目录是给读者跳转用的，层级太深反而找不到位置。

### 三级标题长这样

三级标题在目录里缩进一层。标题尽量写成能独立读懂的一句话，读者在目录里扫一眼就能猜到段落内容。

## 列表

无序列表放并列项，有序列表放有先后关系的步骤：

1. 新建 `.mdx` 文件，文件名就是 slug
2. 开头写好 metadata
3. 正文用 Markdown 写完，保存即可

嵌套列表用两空格缩进：

- 部署
  - Cloudflare Pages：完整功能，含评论
  - GitHub Pages：纯静态，评论关闭
- 本地开发
  - `pnpm dev` 起开发服务器
  - `pnpm preview:cf` 预览评论接口

## 任务清单

任务清单适合展示「做到哪一步了」这类有状态的内容：

- [x] 决定站名和作者信息
- [x] 修改 `src/lib/site.ts`
- [ ] 写第一篇正式文章
- [ ] 配置自定义域名

## 表格

表格自动带横向滚动容器，列再多也不会把窄屏撑破：

| 场景 | 推荐元素 | 原因 |
| --- | --- | --- |
| 操作步骤 | 有序列表 | 有先后关系 |
| 参数对照 | 表格 | 需要横向对比 |
| 补充说明 | 引用块 | 与正文区分开 |
| 命令与代码 | 代码块 | 保留格式、可复制 |

## 引用与分隔线

> 引用块适合放强调性的一句话、补充说明或者转载声明。不要拿它当普通段落用，满屏引用块的文章很难读。
